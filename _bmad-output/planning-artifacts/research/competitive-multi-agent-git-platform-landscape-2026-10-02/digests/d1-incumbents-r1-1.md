# D1 — Incumbent developer platforms: multi-agent capabilities (as shipped), 2026-10-02

Scope: what major incumbent dev platforms actually ship for **multiple AI coding agents working concurrently on the same codebase**, with emphasis on any human surface for reviewing/comparing/integrating multiple concurrent agent-produced changes at once. All findings evidenced by sources retrieved this run. Line format: `- CLAIM | SOURCE | PUBLISHER | PUB_DATE | ACCESSED | CONFIDENCE | CLASS`.

## Findings

- CLAIM (shipped): Cursor Cloud Agents integrated into Graphite (announced Mar 2, 2026) — a Graphite "Agents" tab launches Cursor Cloud Agents that open draft PRs; an Agent tab inside the PR page lets the agent iterate on the branch from reviewer comments/CI; agent threads move between Cursor and Graphite "with full history and context preserved." - CLAIM (shipped): Graphite supports stacked PRs and multiple Git worktrees (gt 1.8.4+), letting reviewers work across a stack of dependent PRs. | SOURCE: https://www.graphite.com/docs/multiple-worktrees | PUBLISHER: Graphite Docs | PUB_DATE: unknown | ACCESSED: 2026-10-02 | CONFIDENCE: high | CLASS: capability
