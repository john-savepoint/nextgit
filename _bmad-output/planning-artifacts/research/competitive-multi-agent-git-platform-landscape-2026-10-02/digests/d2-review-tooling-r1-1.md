## Not found

- No vendor retrieved that REVIEWS MULTIPLE CONCURRENT AGENT PROPOSALS AS A SET. Every review product seen (CodeRabbit, Greptile, Qodo, Macroscope Code Review) reviews one PR/change at a time. Merge-queue vendors (Trunk, Mergify, Aviator) are the only tools reasoning about multiple concurrent changes as a set — but at the CI/batch/merge-integration layer, not semantic review of agent proposals. Macroscope Murmur coordinates a fleet but still lands each change as its own PR.
- Explicit visual/spatial diff review, provenance/decision-log review surfaces, and secret-aware review: no vendor material found this run.
- Public pricing for Macroscope, Trunk, and Mergify (all "Contact/Book Demo" or not captured) — unknown.
- Ellipsis, Kodus, Bors-NG, Reviewpad, Cursor Bugbot, Cubic: no fresh primary source retrieved within budget.
