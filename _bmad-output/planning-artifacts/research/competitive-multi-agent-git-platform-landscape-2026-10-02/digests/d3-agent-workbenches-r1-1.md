- No evidence of automated cross-agent change comparison/reconciliation ("these 3 agents all edited line X — here's what ships"), beyond per-agent conflict flagging.
- No Cloudflare Artifacts–based agent workbench product.
- No ≥3-month-fresh pricing figures for Conductor, Sculptor, Superset, or Nimbalyst (pricing pages not read this run).
