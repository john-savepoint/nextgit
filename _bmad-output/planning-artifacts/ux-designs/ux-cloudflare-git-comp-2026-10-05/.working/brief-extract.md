## 2. Stakes / positioning

- Executive framing, verbatim: "The bottleneck has moved from *writing* changes to *converging* them" and "Integration, not generation, is the crisis." (`brief.md:12`); stats: "~41.7% of concurrent agent pairs conflict; frontier models catch only 15–31% of human-flagged issues." (`brief.md:12`)
- Core bet, verbatim: "The core bet: **the convergence layer** — the set-level surface where concurrent agent work is compared, judged, and merged — is the missing piece of the agent era, and nobody ships it today (verified across six independent competitive sweeps)." (`brief.md:14`)
- Now-moment / substrate: "Why now: the substrate just arrived. Cloudflare's Artifacts gives a programmable git-compatible repo fabric; Workers, Queues and Durable Objects give orchestration; Clef — Cloudflare's open decision model, built for hot-path typed decisions at ~39–209 ms — makes judgment cheap enough to run on every change." (`brief.md:16`); "NextGit is built end-to-end on that stack, works today (real agents, real proposals, real collisions, real one-click landings)" (`brief.md:16`).
- Differentiation: unoccupied category "with real conflict computation (6+ verified sweeps; nearest — GitGhost, private beta; Whiteboard, single-branch local; Entire, announced and unshipped)" (`brief.md:28`); "The honest moat is timing, execution speed, and the unclaimed category — not a proprietary algorithm" [ASSUMPTION] (`brief.md:29`); "API-first by construction. … The platform is the heart; clients are surfaces." (`brief.md:30`); "Trust as a first-class layer. … No surveyed code host treats secret files as typed, access-controlled objects (absence un-falsified)." (`brief.md:31`).
- Stakes/gate: "**Gate (Oct 14):** the submitted entry — 5–10 minute video + open-source repo + run instructions — demonstrating all three rubric axes on real infrastructure (originality/prototype 50%, multi-agent concurrency 25%, UX 25%)." (`brief.md:39`)
- Success criteria beyond demo: "a team uses the API in anger; a second client (e.g., the office) renders live platform state; proposals landed per week with attached evidence becomes a tracked metric." (`brief.md:41`)
- Vision endgame, verbatim: "**make GitHub irrelevant** — not by cloning it, but by making the layer it lacks the layer everyone uses." (`brief.md:51`), flagged "[ASSUMPTION] 'Make GitHub irrelevant' is the founder's stated ambition, retained as directional" (`brief.md:51`).
- Supporting numbers in addendum: 41.7% across 33,596 agent-authored PRs (feature-matrix dossier, arXiv study) (`addendum.md:15`); "GitHub merge-queue silent-deletion incident: 2,092 PRs across 230 repos, 3h33m undetected" (`addendum.md:20`); Clef "$0.24 / $0.09 per M input tokens; Apache-2.0 weights; System One API (Jev-compatible); measured cost ≈ $0.00012/judgment (2026-10-05)" (`addendum.md:19`); "3 finalists present live at Cloudflare Connect (Oct 21)" (`addendum.md:18`).
