The paradigm, decoded

Commands — writes

Every git write funnels through one gated path: POST /land — fold the chosen proposal set, create one commit, push. Provisioning and token minting live in the control plane (scripts → Workflows).

Queries — reads

Binding-native, side-effect-free, never cloning: /changes, /proposals, /merge preview, /events — all within the Workers CPU budget.

Judgment — delegated

Typed decisions go to Clef via one /judge endpoint; policy, weights, and thresholds stay in code. The judge advises; code decides; humans own irreversible acts.

    The /land push-failure path returned a working write token inside a shell snippet; the snippet interpolated repo content into a command line. Real, internet-reachable, demo account.

  2. Fixed — same hour

    Token handout and shell snippets removed (failures now return fold artifacts only); worker-minted tokens made single-use (300 s TTL, revoked in a finally); the land.mjs replay path removed — it now delegates to /land.

  3. Deployed

    Commit d0d8b17 → worker version 87958c11 → live smoke green.

  4. Proven — exercised, not assumed

    A concurrent-land race on a scratch fleet produced real push failures: 2 of 4 calls → 500, every failure body credential-free. A read_only probe then proved the platform's read_only flag does not constrain binding-level writes — write protection must be ours (auth seam).

  5. Closed as rules

    All five adversarial divergence pairs folded into AD-1/3/4/5/6/8/9/10/11 (+ conventions); contract-first, evidence carriers, and the land-hardening preconditions queued as work orders.
